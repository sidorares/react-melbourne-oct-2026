<Notes>

All of these are in @react-x11/components, and all are built from the public host elements, with no private hooks into core. When a component needs something core doesn't expose, that becomes a core issue.

You saw most of them in the demo already. Two are big enough to call out.

Scene3D, the galaxy shot in the demo: a react-three-fiber-shaped scene graph, same element names, prop shapes, attach, useFrame, useThree, extend(), so an r3f component ports with its structure intact. Underneath there is no three.js and no WebGL. It is a second React reconciler drawing into core's `<glarea>`, the 3D escape hatch from the toolkit slide: indirect GLX (GL 1.x encoded into the X connection, survives ssh -X, no shaders), or direct GL ES 2 on the GPU (DRI3 on Linux, CGL into a CALayer on macOS) with shaderMaterial and post-processing. Same JSX on all of them. The galaxy was 200,000 stars as one points draw, moved entirely by uniforms.

Keep the HTML one in mind for the next slide.

</Notes>
